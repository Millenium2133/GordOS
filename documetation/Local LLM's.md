**Getting Started With The LLM's**
This will be a short setup guide to help you get started with using local LLM's on your machine. The LLM's listed below in [[#Recommended Models]] are LLM's that I have tested and have *officially* approved of, however, any model you see fit will work. Feel free to use whatever model and/or LLM software you see fit, this is just a guide for people who want to use a local LLM but may need some guidance.

---
### Ollama

Ollama is the tool that will be used for [[Visual Studio Code]] and [[GordOS]] as it is the easiest way to get set up and is in my opinion the best (you may have a different opinion, and that's okay.)

**Steps**
1. run the official install command in your terminal which can be found at [The Official Ollama Website](https://ollama.com/download)

2. After the install script has finished, type
	```bash
	ollama pull qwen2.5-coder:7b
	```
	and/or
	```bash
	deepseek-coder:6.7b
	```

3. run
	```bash
	ollama serve
	```
	You may get an error
	```bash
	listen tcp your.local.ip:11434: bind: address already in use
	```
	This is okay, copy and paste the local IP into your browser, and you should see a message that says **Ollama is running**

4. That's it for Ollama setup.

### Continue.dev

continue.dev is a Visual Studio Code extension that allows you to use your local LLM's in the editor. You will need to point continue to ollama by configuring its JSON file.

After installing continue.dev from the extensions tab, you will need to access its config.json file by clicking on it's sidebar gear icon.

#### If You Are Using Only Qwen
Add this
```json
{
  "models": [
    {
      "title": "Qwen2.5-Coder Local",
      "provider": "ollama",
      "model": "qwen2.5-coder:7b",
      "apiBase": "http://localhost:11434"
    }
  ],
  "tabAutocompleteModel": {
    "title": "Qwen2.5-Coder Autocomplete",
    "provider": "ollama",
    "model": "qwen2.5-coder:7b"
  }
}
```

#### If You Are Using Only Deepseek
Add this
```json
{
  "models": [
    {
      "title": "DeepSeek-coder Local",
      "provider": "ollama",
      "model": "deepseek-coder:6.7b",
      "apiBase": "http://localhost:11434"
    }
  ],
  "tabAutocompleteModel": {
    "title": "DeepSeek-Coder Autocomplete",
    "provider": "ollama",
    "model": "deepseek-coder:6.7B"
  }
}
```

#### If You Are Using Both
Add this
```json
{
  "models": [
    {
      "title": "Qwen2.5-Coder 7B",
      "provider": "ollama",
      "model": "qwen2.5-coder:7b",
      "apiBase": "http://localhost:11434",
      "contextLength": 8192
    },
    {
      "title": "DeepSeek-Coder 6.7B",
      "provider": "ollama",
      "model": "deepseek-coder:6.7b",
      "apiBase": "http://localhost:11434",
      "contextLength": 8192
    }
  ],
  "tabAutocompleteModel": {
    "title": "Qwen2.5-Coder Autocomplete",
    "provider": "ollama",
    "model": "qwen2.5-coder:1.5b",
    "apiBase": "http://localhost:11434"
  },
  "tabAutocompleteOptions": {
    "useCache": true,
    "maxPromptTokens": 1024
  },
  "embeddingsProvider": {
    "provider": "ollama",
    "model": "nomic-embed-text",
    "apiBase": "http://localhost:11434"
  },
  "allowAnonymousTelemetry": false
}
```

After adding all the models you need/want, you are now ready to use them, however, if you are using an RTX 2060 6GB or equivalent, I recommend reading the [[#Recommended Models]] section.

# Recommended Models

**qwen2.5-coder:7b**
Qwen is best used for the more general purpose tasks of development, like implementing small features, bug fixes, and git commits. Overall it is a decently performing model for the more general tasks of this project.

**deepseek-coder:6.7b**
DeepSeek Coder is a much more demanding model. While it does work, it is noticeably slower, however it's output code is higher quality. The use case for this model should mainly be for more advanced features and major changes to the codebase as well as major bugs/flaws that Qwen is unable to fix or find.
